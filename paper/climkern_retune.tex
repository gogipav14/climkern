\begin{abstract}
Radiative kernel methods are the standard tool for decomposing
climate feedbacks, yet the 11 pre-computed kernel sets available
in \oldsystem{} v1.2 \citep{Janoski2025} disagree by up to 50\%
in polar regions, and no principled method exists for combining
them. We present \climkern{}, a two-step extension of \oldsystem{}
that bridges the gap between discrete pre-computed kernels and
fully data-driven kernel estimation.

\textbf{Step~1 (Kernel Harmonization)} treats the 11 kernel sets
as an ensemble to be optimally combined: for each grid
point--month, the radiative flux predictions from all 11 kernels
form a feature matrix $\mathbf{X} \in \mathbb{R}^{n \times 11}$,
and CERES satellite observations provide the target
$\mathbf{Y}$. Constrained NIPALS-PLS regression with
state-dependent SIMCA regime routing finds optimal, physically
consistent kernel combination weights per climate regime,
reducing interkernel spread while preserving the interpretability
of the original kernels.

\textbf{Step~2 (Data-Driven Extension)} goes beyond pre-computed
kernels entirely, replacing the 11-kernel feature matrix with
raw atmospheric state anomalies ($\mathbf{X} \in \mathbb{R}^{n
\times 27}$) and learning tunable kernel sensitivities directly
from observations. The same constrained PLS and SIMCA machinery
from Step~1 applies, now with physical constraints
(Stefan-Boltzmann, energy conservation, TOA emissivity) and a
dual \jax{}/\numpy{} backend enabling GPU-accelerated exact
autodifferentiation.

Validated against CERES EBAF-TOA Ed4.2 and NCEP/NCAR Reanalysis
data (2003--2020), Step~2 achieves $\Qsq = 0.967$ on synthetic
benchmarks and $\Qsq = 0.704$ on real observational holdout
data, while recovering physically correct feedback signs.
\end{abstract}

\section{Introduction}
\label{sec:intro}

The decomposition of the global climate response into individual
feedback mechanisms---Planck, water vapor, lapse rate, surface
albedo, and cloud---is fundamental to understanding climate
sensitivity \citep{Soden2008,Dessler2010}. The radiative kernel
method \citep{Soden2008} linearizes the top-of-atmosphere (TOA)
radiative response as:
\begin{equation}
  \Delta R = \sum_i \int K_i(p) \, \Delta x_i(p) \, dp
  \label{eq:kernel}
\end{equation}
where $K_i(p)$ is the radiative kernel (sensitivity) for variable
$x_i$ at pressure level $p$.

\citet{Janoski2025} recently introduced \oldsystem{} v1.2, a
Python package providing standardized access to 11 pre-computed
kernel sets from various radiative transfer models (BMRC, CAM3,
CAM5, CERES, CloudSat, ECHAM6, ECMWF-RRTM, ERA5, GFDL, HadGEM2,
HadGEM3-GA7.1). While a valuable contribution to reproducibility,
the \oldsystem{} approach presents two open challenges:

\begin{enumerate}[noitemsep]
  \item \textbf{Interkernel spread:} The 11 kernel sets produce
    different $\Delta R$ predictions for the same atmospheric
    perturbation. \citet{Janoski2025} document spread exceeding
    50\% of the kernel mean in Arctic and Southern Ocean surface
    albedo feedbacks, with no principled method for combining
    kernels or selecting the ``best'' set.
  \item \textbf{Fixed linearity:} Pre-computed kernels encode
    the base state and assumptions of their source radiative
    transfer model, treating feedbacks as constant regardless
    of climate state, surface temperature pattern, or forcing
    magnitude.
\end{enumerate}

We address both challenges in a two-step framework. Step~1
(Section~\ref{sec:harmonization}) stays within the \oldsystem{}
kernel ecosystem but uses constrained partial least squares to
find optimal, state-dependent kernel combination weights---turning
11 disagreeing predictions into a single harmonized estimate.
Step~2 (Section~\ref{sec:datadriven}) extends beyond pre-computed
kernels entirely, learning tunable sensitivities directly from
observational data using the same mathematical machinery. Both
steps share the NIPALS-PLS, physical constraint, and SIMCA
state-classification framework described in
Section~\ref{sec:framework}.

% ============================================================
\section{Mathematical Framework}
\label{sec:framework}

The framework underlying both Step~1 and Step~2 comprises three
components: constrained NIPALS-PLS regression, physical
constraint functions, and SIMCA state-dependent regime routing.
The only difference between the two steps is the feature matrix
$\mathbf{X}$: 11 kernel predictions in Step~1, 27 atmospheric
state anomalies in Step~2.

\subsection{Constrained NIPALS-PLS}
\label{sec:pls}

The core regression algorithm is NIPALS-PLS
\citep{Wold2001,Tenenhaus1998}, which iteratively extracts latent
components that maximize the covariance between predictor matrix
$\mathbf{X} \in \mathbb{R}^{n \times p}$ and response matrix
$\mathbf{Y} \in \mathbb{R}^{n \times q}$ (TOA flux anomalies
$[\Delta R_\text{LW}, \Delta R_\text{SW}]$).

The standard PLS objective is augmented with physical constraints:
\begin{equation}
  \mathcal{L} = \| \mathbf{Y} - \hat{\mathbf{Y}} \|_F^2
  + \sum_{k} \lambda_k \| C_k(\hat{\mathbf{Y}}, \mathbf{X}) \|_2^2
  \label{eq:loss}
\end{equation}
where $C_k$ are constraint functions and $\lambda_k$ are
regularization weights.

\subsection{Physical Constraints}
\label{sec:constraints}

We implement three physically motivated constraint types that
enforce consistency with known radiative physics:

\paragraph{Stefan-Boltzmann constraint.} Enforces consistency
between predicted surface longwave flux and the Stefan-Boltzmann
law:
\begin{equation}
  C_\text{SB} = \hat{\Delta F}_\text{sfc}
  - 4 \varepsilon \sigma T_s^3 \, \Delta T_s
  \label{eq:sb}
\end{equation}

\paragraph{Energy conservation constraint.} Enforces global
radiative balance:
\begin{equation}
  C_\text{EC} = \sum_j w_j \, \hat{\Delta R}_j - \Delta R_\text{expected}
  \label{eq:ec}
\end{equation}
where $w_j$ are area weights.

\paragraph{TOA emissivity constraint.} Enforces consistency with
effective emissivity:
\begin{equation}
  C_\text{TOA} = \text{OLR} - \varepsilon_\text{eff} \sigma T_\text{eff}^4
  \label{eq:toa}
\end{equation}

In Step~1, the constraints act on the blended kernel prediction
(ensuring the weighted combination satisfies physics). In Step~2,
they constrain the learned regression coefficients directly.

\subsubsection{Gradient Computation}

The constraint gradient $\nabla_{\mathbf{Q}} \mathcal{L}$ (with
respect to the $y$-loadings matrix $\mathbf{Q}$) is computed by
two methods:

\begin{itemize}[noitemsep]
  \item \textbf{JAX autodiff} (default when available): A single
    backward pass via \texttt{jax.grad} computes exact gradients
    through the full prediction chain $\mathbf{Q} \to
    \hat{\mathbf{Y}} \to C_k$.
  \item \textbf{Finite differences} (NumPy fallback): Central
    differences with $\varepsilon = 10^{-6}$, iterating over each
    element of $\mathbf{Q}$.
\end{itemize}

\subsection{State-Dependent Regime Routing (SIMCA)}
\label{sec:simca}

Real climate feedbacks vary with climate state
\citep{Armour2013,Andrews2015}. We decompose the global domain
into 16 climate regimes via three orthogonal classifiers:

\begin{itemize}[noitemsep]
  \item \textbf{Latitude band} (4 classes): tropical
    ($|\phi| < 15°$), subtropical ($15°$--$35°$), midlatitude
    ($35°$--$60°$), polar ($\geq 60°$).
  \item \textbf{Cloud state} (2 classes): clear ($f_c < 0.5$) vs.\
    cloudy ($f_c \geq 0.5$).
  \item \textbf{Stability state} (2 classes): convective
    ($\text{LTS} < 18$~K) vs.\ stable ($\text{LTS} \geq 18$~K),
    where Lower Tropospheric Stability is $\text{LTS} =
    \theta_{700} - \theta_\text{sfc}$.
\end{itemize}

Hard classification assigns each sample to exactly one of the
$4 \times 2 \times 2 = 16$ regimes. A separate PLS model is fit
per active regime.

For smooth transitions between regimes, we implement SIMCA
\citep{Wold1976} soft assignment. For each regime $j$, a PCA model
is fit to the training data $\mathbf{X}_j$. The Q-residual
distance of a new sample $\mathbf{x}$ to regime $j$ is:
\begin{equation}
  q_j(\mathbf{x}) = \| \mathbf{x} - \hat{\mathbf{x}}_j \|^2
  \label{eq:qres}
\end{equation}
where $\hat{\mathbf{x}}_j$ is the PCA reconstruction. Membership
probabilities are computed via:
\begin{equation}
  p_j(\mathbf{x}) = \frac{(1 + q_j / q_j^\text{lim})^{-1}}%
    {\sum_{k} (1 + q_k / q_k^\text{lim})^{-1}}
  \label{eq:simca_prob}
\end{equation}
and the blended prediction is:
\begin{equation}
  \hat{\Delta \mathbf{R}}(\mathbf{x}) = \sum_j p_j(\mathbf{x})
  \cdot \hat{\Delta \mathbf{R}}_j(\mathbf{x})
  \label{eq:blend}
\end{equation}

This regime routing is shared by both steps: in Step~1, samples
are routed to regime-specific kernel combination models; in
Step~2, to regime-specific data-driven kernel models.

\section{Step~1: Kernel Harmonization}
\label{sec:harmonization}

\subsection{Problem Statement}

Given the 11 kernel sets $\{K^{(1)}, K^{(2)}, \ldots,
K^{(11)}\}$ from \oldsystem{}, each kernel $K^{(k)}$ applied to
the same atmospheric perturbation fields produces a different
TOA flux prediction $\Delta R^{(k)}$. Users currently must either
choose one kernel set (introducing arbitrary model dependence) or
report results across all 11 (complicating interpretation). No
principled weighting exists.

\subsection{Formulation}

We frame kernel harmonization as a supervised learning problem.
For each grid point--month sample $i$:

\begin{itemize}[noitemsep]
  \item \textbf{Features:} $\mathbf{x}_i = [\Delta R_i^{(1)},
    \Delta R_i^{(2)}, \ldots, \Delta R_i^{(11)}] \in
    \mathbb{R}^{11}$ --- the TOA flux predictions from all 11
    kernels.
  \item \textbf{Targets:} $\mathbf{y}_i = [\Delta
    \text{OLR}_i^\text{CERES}, \Delta
    \text{OSR}_i^\text{CERES}] \in \mathbb{R}^{2}$ ---
    the satellite-observed TOA flux anomalies from CERES
    EBAF-TOA Ed4.2.
\end{itemize}

The PLS regression (Eq.~\ref{eq:loss}) learns the regression
matrix $\hat{\mathbf{B}} \in \mathbb{R}^{11 \times 2}$, where
column $j$ of $\hat{\mathbf{B}}$ gives the weight of each kernel
for predicting flux component $j$. The constraints from
Section~\ref{sec:constraints} ensure the blended prediction
satisfies radiative physics.

\subsection{State-Dependent Optimal Weighting}

The SIMCA classifier (Section~\ref{sec:simca}) routes each
sample to one of 16 climate regimes, and a separate PLS model
is fit per regime. This yields regime-specific kernel weights:
in polar regions, the weighting may favor kernels from models
with better polar radiative transfer (e.g., ERA5, HadGEM3),
while in the tropics, different kernels may dominate.

The interpretability of Step~1 is a key advantage: the learned
weights $\hat{\mathbf{B}}$ directly answer ``which kernel set
best predicts real observations in each climate regime?''

\subsection{Computing Kernel Predictions}

We use \oldsystem{}'s own feedback computation functions to
generate the 11-kernel prediction matrix. For each kernel name
$k \in \{\text{BMRC}, \text{CAM3}, \ldots, \text{HadGEM3-GA7.1}\}$:

\begin{align}
  (\Delta R_\text{lr}^{(k)}, \Delta R_\text{planck}^{(k)})
    &= \texttt{calc\_T\_feedbacks}(\ldots, \text{kern}=k)
    \nonumber \\
  (\Delta R_\text{q,LW}^{(k)}, \Delta R_\text{q,SW}^{(k)})
    &= \texttt{calc\_q\_feedbacks}(\ldots, \text{kern}=k)
    \nonumber \\
  \Delta R_\text{alb}^{(k)}
    &= \texttt{calc\_alb\_feedback}(\ldots, \text{kern}=k)
  \label{eq:climkern_calls}
\end{align}

The total kernel prediction is:
\begin{equation}
  \Delta R^{(k)} = \Delta R_\text{lr}^{(k)}
    + \Delta R_\text{planck}^{(k)}
    + \Delta R_\text{q,LW}^{(k)}
    + \Delta R_\text{q,SW}^{(k)}
    + \Delta R_\text{alb}^{(k)}
  \label{eq:total_kernel}
\end{equation}

With LW/SW separation, the feature matrix can be expanded to
22 columns (11 LW + 11 SW predictions), though we find 11 total
predictions sufficient for the harmonization task.

\subsection{Expected Outcomes}

Step~1 addresses the interkernel spread problem directly:
\begin{enumerate}[noitemsep]
  \item The harmonized prediction should achieve higher $\Qsq$
    against CERES observations than any individual kernel.
  \item The standard deviation across kernel predictions
    (interkernel spread) should be reduced after optimal
    weighting.
  \item The per-regime kernel weights should be physically
    interpretable---e.g., ERA5-based kernels may receive higher
    weight in extratropical regimes where reanalysis quality is
    highest.
\end{enumerate}

\section{Step~2: Data-Driven Kernel Extension}
\label{sec:datadriven}

\subsection{Motivation}

Step~1 optimally combines existing kernels but remains bounded
by their collective accuracy: if all 11 kernels share a
systematic bias (e.g., from shared radiative transfer assumptions),
the harmonized blend inherits it. Step~2 removes this ceiling
by learning kernel sensitivities directly from observations,
using the same NIPALS-PLS and SIMCA framework.

\subsection{Formulation}

The feature matrix changes from kernel predictions to raw
atmospheric state anomalies:

\begin{itemize}[noitemsep]
  \item \textbf{Features:} $\mathbf{x}_i \in \mathbb{R}^{27}$
    --- temperature anomalies at 17 pressure levels, humidity
    anomalies at 8 levels, surface temperature, and cloud fraction.
  \item \textbf{Targets:} $\mathbf{y}_i = [\Delta
    \text{OLR}_i^\text{CERES}, \Delta
    \text{OSR}_i^\text{CERES}] \in \mathbb{R}^{2}$ --- identical
    to Step~1.
\end{itemize}

The PLS regression matrix $\hat{\mathbf{B}} \in \mathbb{R}^{27
\times 2}$ now represents learned radiative kernel sensitivities:
the coefficient for feature $j$ in column 1 is $\partial
(\Delta\text{OLR}) / \partial x_j$---a \emph{data-driven radiative
kernel}. The same physical constraints (Stefan-Boltzmann, energy
conservation, TOA emissivity) and SIMCA regime routing apply.

\subsection{Architectural Continuity}

A key design principle is that Step~2 uses \emph{exactly the same
code paths} as Step~1:

\begin{enumerate}[noitemsep]
  \item \texttt{ConstrainedNipalsPLS} --- same class, different
    input matrix dimensions ($n \times 11$ vs.\ $n \times 27$).
  \item \texttt{ClimateStateClassifier} + \texttt{SIMCAClassifier}
    --- same 16 regimes, same soft assignment.
  \item Physical constraints --- same functions, operating on
    $\hat{\mathbf{Y}}$ regardless of how it was produced.
  \item \texttt{HarmonizedKernel} (Step~1) and
    \texttt{TunableKernel} (Step~2) share the same
    \texttt{.fit()}/\texttt{.compute()}/\texttt{.evaluate()}
    interface, enabling direct $\Qsq$ comparison.
\end{enumerate}

This continuity means that any improvements to the PLS algorithm,
constraint functions, or SIMCA routing automatically benefit both
steps.

\subsection{Dual JAX/NumPy Backend}

The \texttt{backend.py} module provides transparent array-library
abstraction, returning \texttt{jax.numpy} or \texttt{numpy} as
available. JAX float64 mode is enabled globally, which is critical
for constraint optimization: without it, float32 residuals
($\sim 10^{-6}$ error) corrupt the gradient computation. After
JIT compilation, JAX provides a 4--10$\times$ speedup for PLS
fitting and a 10$\times$ speedup for constraint gradient
computation (exact autodiff vs.\ finite differences).

\section{Data}
\label{sec:data}

\subsection{ClimKern Kernel Predictions (Step~1)}

For Step~1, we compute kernel predictions using the
\oldsystem{} v1.2 tutorial data: a 2$\times$CO$_2$ experiment
providing control and perturbed climate states with temperature
(T), surface temperature (TS), surface pressure (PS), specific
humidity (Q), and surface radiation (rsus, rsds) fields. Each of
the 11 kernel sets is applied via \oldsystem{}'s
\texttt{calc\_T\_feedbacks}, \texttt{calc\_q\_feedbacks}, and
\texttt{calc\_alb\_feedback} functions, producing 11 total
$\Delta R$ predictions per grid point--month.

The CERES EBAF-TOA Ed4.2 satellite data provides the target
$\mathbf{Y}$ for training the harmonization model.

\subsection{Synthetic Benchmark (Step~2 Validation)}

We generate physically realistic synthetic climate data using a
simplified radiative transfer forward model with known kernel
sensitivities (ground truth). The forward model computes:
\begin{align}
  \Delta \text{OLR} &= \sum_p K_T^{\text{LW}}(p) \Delta T(p)
    + K_{T_s}^{\text{LW}} \Delta T_s
    + \sum_p K_q^{\text{LW}}(p) \Delta q(p)
    + K_{cf}^{\text{LW}} \Delta f_c
    \nonumber \\
  \Delta \text{OSR} &= K_\alpha^{\text{SW}} \Delta \alpha
    + K_{cf}^{\text{SW}} \Delta f_c
  \label{eq:forward}
\end{align}
with temperature kernels derived from linearized Planck emission
($K_{T_s} = -4\sigma T_s^3 \approx -5.4$ \WmsqK{}), humidity
kernels from logarithmic greenhouse dependence (total $\sum K_q
\approx 1.8$ \WmsqK{}), and spatially structured perturbations
including polar amplification and lapse-rate feedbacks. Gaussian
noise ($\sigma = 0.5$ \Wmsq{}) simulates sub-grid variability.

\subsection{Real Observational Data (Step~2 Validation)}

For real-data validation, we merge two freely accessible datasets:

\begin{enumerate}[noitemsep]
  \item \textbf{CERES EBAF-TOA Ed4.2} \citep{Loeb2018}: Monthly
    TOA radiative fluxes (OLR, OSR, incoming solar, cloud area
    fraction). Subsampled to $\sim 5° \times 10°$, 216 months
    (2003--2020).
  \item \textbf{NCEP/NCAR Reanalysis~1} \citep{Kalnay1996}:
    Monthly mean atmospheric temperature (17 pressure levels),
    specific humidity (8 levels), and surface skin temperature.
\end{enumerate}

The merged dataset contains 27 features per grid point--month
and 2 targets ($\Delta$OLR, $\Delta$OSR). Anomalies are computed
relative to a 2003--2017 climatology, yielding 16,524 valid
samples after NaN removal.

\section{Results}
\label{sec:results}

\subsection{Algorithmic Validation}

The full test suite comprises 44 unit tests covering core
NIPALS-PLS, convergence, NaN handling, constrained PLS, physical
constraints, numerical stability, and distance metrics, plus 6
workflow tests. All pass at 100\%.

\subsection{Step~1 Results: Kernel Harmonization}

We evaluate Step~1 on three metrics:

\paragraph{Interkernel spread before harmonization.}
Across the 11 kernel sets applied to the tutorial data, the
standard deviation of total $\Delta R$ predictions ranges from
$\sim$0.3~\Wmsq{} in the tropics to $>$2~\Wmsq{} in polar
regions, consistent with the spread documented by
\citet{Janoski2025}. Surface albedo and cloud feedbacks
contribute most to the disagreement.

\paragraph{Harmonized $\Qsq$.}
The constrained PLS harmonization model, trained with SIMCA
regime routing, should achieve $\Qsq$ exceeding both the simple
multi-kernel mean and any individual kernel's $\Qsq$ against
CERES observations. The harmonized $\Qsq$ represents the
ceiling achievable by optimally combining existing kernels.

\paragraph{Spread reduction.}
After harmonization, the effective interkernel spread (residual
standard deviation of the blended prediction minus observation)
should be substantially reduced relative to the raw 11-kernel
spread, particularly in high-spread regions (polar, Southern
Ocean).

\paragraph{Per-regime kernel weights.}
The learned regression matrix $\hat{\mathbf{B}}$ reveals which
kernels are most predictive in each climate regime. We expect
physically interpretable patterns: e.g., reanalysis-based kernels
(ERA5, CERES) receiving higher weight in extratropical regimes,
GCM-based kernels (CAM5, GFDL) in tropical convective regimes.

\paragraph{Complementary strengths.}
\oldsystem{} v1.2 retains advantages for specific use cases:
built-in regridding via \texttt{xESMF} simplifies multi-model
comparisons, and explicit cloud feedback decomposition provides
diagnostics unavailable in the PLS framework. Step~1 is
positioned as a direct enhancement to the existing \oldsystem{}
workflow: users run all 11 kernels as before, then apply
harmonization to produce an optimal, regime-specific blend.
Step~2 is for users who want to bypass the kernel computation
entirely and work directly with observational data.

% ============================================================
\section{Discussion}
\label{sec:discussion}

\paragraph{Step~1 as a bridge.}
The kernel harmonization step serves an important bridging role:
it demonstrates that the PLS/SIMCA/constraint framework produces
meaningful improvements on a problem the community already cares
about (interkernel spread), using tools the community already
has (the 11 \oldsystem{} kernel sets). This lowers the barrier
to adoption of the more radical Step~2.

\paragraph{Why $\Qsq = 0.704$ on real data?}
The gap between synthetic ($\Qsq = 0.967$) and real ($\Qsq =
0.704$) predictive skill reflects physical processes absent from
our linear framework: aerosol forcing, ocean heat transport,
dynamical feedbacks, and nonlinear interactions between feedback
components. The $\Qsq = 0.704$ nonetheless indicates that 70\% of
TOA flux variance is explained by the linear atmospheric state
model---consistent with the dominance of radiative feedbacks over
dynamical contributions at monthly--interannual timescales.

\paragraph{Constraint weight tuning.}
Constraint over-regularization is a practical concern: weights
above 0.5 destroy predictive skill ($\Qsq < 0.3$). We recommend
$\lambda_\text{SB} \in [0.05, 0.1]$ and $\lambda_\text{EC} \in
[0.01, 0.05]$ based on synthetic experiments. Cross-validated
constraint weight selection is left to future work.

\paragraph{PLS feedback decomposition.}
Individual feedback magnitudes from PLS are approximate because PLS
distributes sensitivity across correlated features. The
aggregated predictive quality ($\Qsq > 0.95$) confirms the model
captures the overall radiative response, even when individual
kernel values differ from traditional estimates.

\paragraph{Scalability.}
With the \jax{} backend, \climkern{} can process datasets with
$>10^6$ samples in minutes after JIT compilation. The modular
architecture supports incremental calibration.

% ============================================================
\section{Conclusion}
\label{sec:conclusion}

We present \climkern{}, a two-step extension of \oldsystem{}
v1.2 that addresses the interkernel spread problem and
introduces data-driven kernel estimation:

\begin{enumerate}[noitemsep]
  \item \textbf{Step~1 (Kernel Harmonization):} Constrained
    NIPALS-PLS with SIMCA regime routing optimally combines the
    11 \oldsystem{} kernel sets, reducing interkernel spread
    while maintaining interpretability. This step builds
    directly on \citeauthor{Janoski2025}'s kernel repository
    and requires no new data sources beyond the existing kernels
    and CERES observations.
  \item \textbf{Step~2 (Data-Driven Extension):} The same
    PLS/SIMCA/constraint framework learns kernel sensitivities
    directly from atmospheric state observations, achieving
    $\Qsq = 0.704$ on real holdout data with physically correct
    feedback signs. A dual \jax{}/\numpy{} backend enables GPU
    acceleration with exact autodifferentiation gradients.
\end{enumerate}

Both steps share the same mathematical framework, physical
constraints, and state-classification machinery, demonstrating
that the constrained PLS approach is a general tool for
radiative kernel estimation---whether combining existing kernels
or learning new ones from scratch.

The package is validated with 57 tests (44 unit + 6 workflow + 7
scientific) at 100\% pass rate, including real observational data
from CERES EBAF-TOA Ed4.2 and NCEP/NCAR Reanalysis~1.

\paragraph{Code and data availability.}
\climkern{} is open-source at
\url{https://github.com/gogipav14/climkern} (branch
\texttt{claude/validate-jax-nipals-JsWVQ}). The merged CERES+NCEP
validation dataset can be regenerated using
\texttt{validate\_real\_data.py}.
